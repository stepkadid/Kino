# Проверка v0.3.0

- Синтаксические проверки четырёх модулей пройдены, все 11 unit-тестов проходят.
- Запрос «киберпанк» уточняется до Cyberpunk Edgerunners. Проверенные источники не вернули подтверждённую полную серию. Обзоры, радио, игровые стримы Cyberpunk 2077 и подкасты больше не подмешиваются как фильмы.
- Плашка «Ещё больше результатов — на самих площадках» удалена из DOM.
- PeerTube: поиск Sintel вернул подходящие публикации. Первая открылась в iframe внутри приложения. С p2p=0 видео достигло readyState 4, duration 888.000006, currentTime 21.132886, paused false. Поток HLS шёл с HTTP-сервера источника.
- Импорт неподдерживаемого iframe отклонён. Ссылка YouTube преобразована в официальный youtube-nocookie.com/embed, открыта в модальном плеере.
- RUTUBE: запросы публичного API из среды проверки возвращали 403. В UI это отображается как ошибка источника; результат поиска или воспроизведения не выдумывается. Разбор официальных embed-ссылок протестирован.
- VK Видео: поддерживается разбор обычной ссылки и официального video_ext.php с hash. Автоматический поиск и воспроизведение конкретного видео VK без предоставленной ссылки не проверены.
- Dailymotion: публичный API поиска отвечает, но актуальный поддерживаемый iframe требует Player ID. Поиск в UI не включается без этого идентификатора. Ни один неподключённый плеер не объявляется рабочим.
- Внешние плееры имеют allowfullscreen и собственные настройки качества. Из cross-origin iframe нельзя достоверно получить состояние ограничений или точную позицию без специального API; приложение этого не обещает.

# Проверка v0.2.0

- `npm run check`: три модуля проходят синтаксическую проверку.
- `npm test`: 5 проверок проходят: реальные высоты вместо имени файла, группировка и порядок серий, проверка URL и лицензии, классификация, построение поискового запроса.
- В Chrome введено «Носферату»: 4 записи Internet Archive и 3 Wikimedia Commons, 5 карточек после удаления дублей. Это результаты API, а не домашняя подборка.
- Воспроизведение найденного Nosferatu через Commons: длительность 5518.741 секунды, WebM, доступно 1080p/480p/240p. После переключения на 240p сохранена позиция 16.556223 секунды и состояние паузы.
- Sherlock Holmes: 39 серий в карточке и плеере. Переход ко второй серии запустил видео, duration 1613.415329, readyState 4, paused false.
- Раздел мультсериалов получает внешние записи, включая Popeye и Betty Boop. Фильтр Wikimedia Commons оставляет записи этого источника.
- Постраничная загрузка общего каталога увеличила число карточек с 33 до 54.
- Добавление His Girl Friday в список, удаление и перезагрузка: состояние сохраняется. Данные списка первой версии перенесены.
- Домашние изображения загрузились, в том числе локальные постер и кадры. Недоступные внешние изображения заменяются SVG-обложкой.
- Мобильный интерфейс визуально проверен в iframe 390×844 в Chrome: поиск, горизонтальный выбор разделов, карточка фильма, нижняя навигация. Физический iPhone/Safari не проверялся.
- Разрешение видео найдено для всех 10 записей домашней подборки: Sintel, Big Buck Bunny, Tears of Steel, Elephants Dream, His Girl Friday, Sita Sings the Blues, Sherlock Holmes, Bonanza, Popeye, Superman. Количество эпизодов: Sherlock 39, Bonanza 30, Popeye 5, Superman 1.

Зависимость от внешних API и серверов сохраняется. Наличие браузерно совместимого файла не гарантирует бесперебойную доступность во всех регионах и браузерах. Реальная классификация внешних записей зависит от их метаданных.
